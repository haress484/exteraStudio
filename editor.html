plugin.plugin
Почему раньше файл не доходил: ссылки tg://msg и tg://resolve только открывают Telegram — они не переносят вложение и не дают выбрать чат для файла. Поэтому здесь нет автоперехода по ссылке: файл уходит через системное меню «Поделиться», а текст — через выбор чата.
  1. Файл plugin.plugin сохранён в «Загрузки».
  2. Откройте Telegram / exteraGram / AyuGram → «Избранное» или нужный чат.
  3. Скрепка → «Файл» → выберите скачанный .plugin → отправить.
  4. В exteraGram нажмите на файл в чате → «Установить плагин».
